# WhatsApp Business Greeting Message

The website opens WhatsApp with a pre-filled customer message only. It cannot send an automatic reply from the business account. Configure the following in the WhatsApp Business app:

WhatsApp Business -> Tools -> Greeting message -> Enable "Send greeting message" -> Add the message below -> Select appropriate recipients -> Save

## Real-world flow

1. Customer opens the website and clicks the existing WhatsApp button.
2. WhatsApp opens with the customer message pre-filled.
3. Customer reviews it and presses Send.
4. The business receives the message in WhatsApp Business.
5. WhatsApp Business sends this configured Greeting Message according to its recipient settings.

The website does not automatically send the owner response and contains no WhatsApp credentials, API keys, or tokens.
